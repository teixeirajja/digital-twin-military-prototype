# APTUS PT/EN Browser/PC patch v2

Esta versão adiciona seletor PT/EN ao browser Streamlit e à app PC que usa os mesmos ficheiros.

## Correções incluídas
- Corrige o bug em que HTML aparecia impresso no login.
- Mantém PT como idioma original por defeito.
- Traduz para EN por cima da interface sem alterar a lógica interna dos botões/filtros.
- Traduz textos principais de login, navegação, filtros, métricas, gráficos e simuladores.
- Não altera o projeto Android.

## Deploy
Faz upload do conteúdo desta pasta para a raiz do repositório GitHub, mantendo `app.py` na raiz.
